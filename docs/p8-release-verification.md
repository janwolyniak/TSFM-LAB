Date: 27 October 2026. Scope: local qualification of the
[v0.2.0 feature plan](next-release-plan.md). The preparation checks recorded below
used package metadata `0.1.0`. Final release metadata and renewed checks are
documented in the [v0.2.0 release record](v0.2.0-verification.md).
The candidate includes P7's language-assistance implementation and current `main`
documentation. P7 was integrated through [PR #10](https://github.com/janwolyniak/TSFM-LAB/pull/10)
before publishing the P8 candidate.

## Qualification checks

The source builder includes the citation file linked from the README, the
qualification scripts, and the retained historical compatibility fixtures.
Artifact identity checks bind packaged source bytes to an explicit Git revision,
wheel modules/resources to the source archive, and installed package bytes to
the supplied wheel. The installed verifier rejects inherited system site
packages before claiming an isolated installation.

Historical compatibility uses fixtures actually generated by the older revision
identified in the [fixture provenance](../tests/fixtures/release_legacy_v1/README.md).
Current configuration, dataset, saved-result, comparison, and finance readers
must accept those original files without rewriting their bytes or changing their
identities. This complements tests of records generated by current code.

  pytest plugin loading disabled. Nine skips concern unavailable Textual coverage;
  five opt-in model checks require explicitly selected local weights. No model
  inference was performed for this milestone.
- After the last two identity regressions were added, the complete focused
  identity/build/installed-verifier suite passed **48 tests** in 10.84 seconds.
  These focused checks cover the final artifact-check changes after the full run.
- Formatting checked 175 Python files; Ruff and whitespace checks passed.
  Documentation checks validated local links, shell/Python example syntax,
  citation metadata, and the existing workflow YAML.
- The preliminary source archive and source-built wheel passed content/metadata
  checks. The wheel contained 102 entries; only NumPy and Pandas remain core
  dependencies, and all three existing license notices are retained.
- All **14 installed-workflow stages passed** in 25.30 seconds, including the
  genuine old-record probe. Exact installed-byte checks matched 94 runtime files
  and seven wheel metadata files. The environment has no system site packages,
  forecasting/provider/kernel/Textual runtimes, or real credentials.
- Dependency consistency passed. Only the local project wheel was replaced in
  the existing disposable verifier environment with `--no-index --no-deps`;
  the complete installed package/version inventory was unchanged. No third-party
  dependency was installed or upgraded.

Identity regressions cover omitted manifest-selected files, changed source/runtime
bytes, dependency/extra/entrypoint drift, invalid wheel metadata, uncommitted files,
and changed/missing/extra installed package files. Independent review repaired
those gaps before the final identity checks. Focused tests also cover inherited
system-site packages and the installed historical-record stage.

Final artifacts are rebuilt after the task commit. The build and identity JSON
