## Qualification checks

The source builder includes the citation file linked from the README, the
qualification scripts, and the retained historical compatibility fixtures.
Artifact identity checks bind packaged source bytes to an explicit Git revision,
wheel modules/resources to the source archive, and installed package bytes to
the supplied wheel. The installed verifier rejects inherited system site
packages before claiming an isolated installation.

Historical compatibility uses fixtures actually generated by the older revision
identified in the [fixture provenance](../tests/fixtures/release_legacy_v1/README.md).
Current configuration, dataset, saved-result, comparison, and finance readers
must accept those original files without rewriting their bytes or changing their
identities. This complements tests of records generated by current code.
