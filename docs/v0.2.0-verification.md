# v0.2.0 release verification

Date: 27 October 2026. Package version: `0.2.0`. Distribution: GitHub release
`v0.2.0`, with a source archive, wheel, SHA-256 checksums, and verification manifest.
The earlier v0.1.0 candidate was not published separately. No PyPI upload is part
of this release.

## Authorization and source freeze

The owner explicitly requested finalizing v0.2.0 and publishing its GitHub release
while keeping CI skipped. This authorizes the focused version/documentation
change, integration, release tag, and GitHub assets. Push/tag/merge commits use
`[skip ci]`; repository protections and workflow configuration are unchanged.
No new live provider/model checks, third-party dependency changes, or paid
requests are included.

Package metadata, `tsfm_lab.__version__`, citation metadata, README badges, release
notes, and current installation examples agree on `0.2.0`. Historical milestone
records and genuine pre-profile compatibility fixtures retain their original
versions. Artifact-identity tests derive current metadata from the project rather
than assuming that future releases remain version 0.1.0.

The source archive and wheel are rebuilt from the final integrated revision.
`verification.json` attached to the GitHub release records that exact commit,
source/wheel hashes and sizes, and the exercised checks. It is created after the
source freeze so its commit and artifact identities cannot be self-referential.
`SHA256SUMS` identifies the source archive, wheel, and verification manifest.

## Local checks

The full source suite passed **2,554 tests**, with **14 skips**, in 58.28 seconds
using `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1`. Nine skips concern optional Textual
coverage; five require explicitly selected local model weights. Black checked
175 Python files; Ruff and whitespace checks passed. Documentation checks cover
relative links, shell/Python example syntax, workflow YAML, and citation metadata.
The local environment uses Python 3.13.6 on macOS. Routine checks use synthetic
fixtures and fake assistant transports.

The preliminary v0.2.0 build passed content and metadata checks with 297 source
entries and 102 wheel entries. The final integrated build and installed-workflow
results are recorded in the release's `verification.json`; preliminary artifact
hashes do not identify final assets. Code, tests, and dependency constraints remain
unchanged by the final documentation freeze.

All 14 preliminary installed-workflow stages passed in 26.545 seconds, including
the old-record compatibility probe and exact installed-wheel byte checks. The
final artifact is reinstalled and checked again after the integrated source freeze.

The source-to-wheel builder runs without dependency resolution or downloads.
Identity checks compare all manifest-selected source bytes with the frozen Git
revision, all runtime modules/resources with the wheel, and installed package and
original metadata bytes with the selected wheel. Only NumPy and Pandas remain
mandatory core dependencies; optional runtimes and license notices are preserved.

Installed checks use an ordinary wheel in the existing disposable environment
without system site packages. Only the project's own wheel is replaced using
`--no-index --no-deps`; dependency consistency is checked separately. Verification
scripts are executed from the delivered source archive in isolated Python mode,
so checkout imports cannot satisfy missing installed modules or fixtures.

## Verification limits

- The owner waived hosted CI for this release. No new Linux/macOS Python
  3.11–3.13 matrix success is claimed for the final revision. Skipped CI remains
  unverified CI; it does not become a passing check.
- Textual-dependent checks skip when that optional package is absent. Real-model
  smoke checks require explicitly selected local weights and remain opt-in.
- Four assistant connection routes are implemented and fake-provider tested.
  Live sign-in/API compatibility, account eligibility, and native credential-vault
  behavior remain unqualified. No real account/credential test is implied.
- Model-specific representative inference records remain bounded to their stated
  implementations, runtime/checkpoint identities, and CPU environment. No new
  checkpoint execution, larger-variant qualification, forecasting ranking, or
  financial-performance claim is added by this release.
- The [P8 preparation record](p8-release-verification.md) remains historical
  evidence. Its 0.1.0 package hashes do not identify these v0.2.0 assets.
